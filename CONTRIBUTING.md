# Contributing to GoOnco

Everyone may propose improvements. No ChatGPT subscription is needed to browse the site. GitHub issues/PRs require a GitHub account; professional expressions of interest can instead go to volunteers@goonco.org. Incoming aliases work; response times and outbound domain email are not promised.

1. Read the README, governance and security policies. Browse issues or propose a small task before substantial changes.
2. Work only on GoOnco code, permitted public source descriptions and synthetic fixtures. Keep business projects, credentials, private contacts and real medical records out of this repository and AI tools.
3. Fork/branch, make a focused change, and document the problem, user benefit, limitations and evidence. Do not fabricate citations, credentials, affiliations or statistics.
4. Run npm run build, npm test and npm run validate. Include meaningful known-answer/denial tests when behavior changes; don't add tests merely to mirror code.
5. Submit a PR using the template. Disclose material AI assistance (tool and scope), independently verify outputs and licenses, and retain human responsibility. Claude, Gemini, Copilot, Codex, Muse, Grok and other tools are welcome subject to their terms; no endorsement or integration is implied.
6. Maintainers review before merge. Scientific/statistical/privacy changes require appropriately qualified review; unfilled review roles block those approvals. No PR or automated test grants clinical authority or source/data approval.

Translations need language, source text, reviewer needs and uncertainty. Patient/caregiver perspectives are welcome without personal health histories.

By submitting a contribution, represent that you have the right to contribute it under this repository's MIT license. Retain attribution and identify third-party material/terms. No patient-data, publication redistribution or AI-training rights are granted by contribution alone. Report conflicting licenses before submitting. Maintainers may request changes or decline work; there is no guaranteed response deadline.

Feedback: feedback@goonco.org. Security: security@goonco.org privately. Privacy: privacy@goonco.org. No automated submission or membership service is implemented.
